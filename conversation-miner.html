Want more than keyword search?

This tool is deliberately basic. Three upgrade paths, any AI coding assistant can add them in an hour.

  • Semantic search Replace the substring match with sentence embeddings. Run each message through a local embedding model (transformers.js) or the Claude API. Then rank by cosine similarity to the query. Finds conceptual matches that keywords miss.
  • LLM-scored quality After keyword matching, send each hit to Claude with a rubric prompt and keep only the highest-scoring N. Useful when you want "best strategic moments" not just "any message containing the word strategy".
  • ChatGPT archive support ChatGPT exports use a different conversations.json shape (messages live under mapping, not chat_messages). Add a format detector and a second extractor. Same drop zone, same output.
  • Topic clustering Group matched excerpts by topic before exporting. Use embeddings plus k-means, or ask an LLM to tag each excerpt with one of a predefined topic set.
  • Direct upload to a new project Wire the output directly into the Claude Projects API so the condensed file is created and attached in one click. Needs API key handling and appropriate CORS setup.

The source is in this page. Open in an editor, paste into your AI of choice, and ask. If you build one of these and it works well, send it back as a pull request. The standard gets better when more people touch it.
